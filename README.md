# Animorize

แอปติดตามสื่อ (Anime, Series, Movie, OVA) แทน Excel

## Getting Started

```bash
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000) ใน browser

## Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm test` | Run tests |
| `npm run lint` | Lint code |
| `npm run typecheck` | Type check |

## Tech Stack

- **Next.js 16** (App Router) + TypeScript strict
- **Tailwind CSS v4** + Supabase (PostgreSQL + Auth + RLS)
- **Zustand v5** + TanStack Query v5 + React Hook Form + Zod
- **Motion v11** + Vitest + RTL
